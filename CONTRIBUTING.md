# Contributing

Das Projekt ist als abgeschlossener, dokumentierter Stand veröffentlicht. Pull Requests können dennoch willkommen sein, es besteht aber kein Anspruch auf Review oder Weiterentwicklung.

Für Änderungen:

1. keine echten Zugangsdaten oder Anlagenexporte committen,
2. bestehende Sicherheitsprüfungen und Readback-Verifikation nicht entfernen,
3. neue Schreibbefehle nur mit nachvollziehbarer API-Evidenz und realer Zustandsprüfung ergänzen,
4. keine Alarmsemantik raten,
5. `npm run check` vor einem Commit ausführen.

Bitte bei neuen Firmwareständen genau dokumentieren, welche Version getestet wurde.
